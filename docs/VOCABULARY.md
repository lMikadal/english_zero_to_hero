# Vocabulary: Oxford 3000 สำหรับชีวิตประจำวัน

## 1. ทำไมเลือก Oxford 3000

**Oxford 3000** คือรายการคำศัพท์หลัก 3,000 คำที่ Oxford คัดจากคำที่ใช้บ่อยที่สุดและสำคัญที่สุดสำหรับผู้เรียน
แต่ละคำมีระดับ CEFR (A1–B2) กำกับไว้ จึงเรียงลำดับการสอนได้ตรงกับหลักสูตร
รู้ครบ 3,000 คำนี้แล้วจะเข้าใจภาษาอังกฤษในชีวิตประจำวันได้ประมาณ 80–90%

**Oxford 5000** คือรายการที่ขยายเพิ่มอีก 2,000 คำ (ระดับ B2–C1) ใช้เป็นคำเสริมในเฟส 4

| ระดับ | จำนวนโดยประมาณ | สอนในเฟส |
|---|---|---|
| A1 | ~900 | 1–2 |
| A2 | ~870 | 2 |
| B1 | ~800 | 3 |
| B2 | ~700 | 4 |
| Oxford 5000 (B2–C1) | เลือกมา ~500 | 4 (เสริม) |

> จำนวนต่อระดับเป็นค่าประมาณ ให้ใช้ตัวเลขจริงจากรายการที่ import เข้ามาแล้ว

## 2. แผนคำศัพท์ 365 วัน

| เฟส | วันที่ | ระดับ Oxford | คำใหม่ต่อวัน | คำสะสม |
|---|---|---|---|---|
| 1. Foundation | 1–60 | A1 (ส่วนที่ใช้บ่อยที่สุด) | ~8 | ~500 |
| 2. Survival | 61–150 | A1 ที่เหลือ + A2 | ~11 | ~1,500 |
| 3. Conversation | 151–270 | B1 | ~7 | ~2,300 |
| 4. Fluency | 271–365 | B2 + Oxford 5000 บางส่วน | ~7–12 | ~3,000–3,500 |

- คำใหม่จะมีเฉพาะวันประเภท `lesson` ส่วนวัน `review`, `challenge` และ `checkpoint` ใช้ทบทวนคำเดิม
- **วันละไม่เกิน 12 คำ** เพราะงานทบทวนใน SRS จะเพิ่มขึ้นทุกวัน
- ลำดับการสอนภายในระดับเดียวกันให้จัดตาม **หัวข้อของบทเรียน** ไม่ต้องเรียงตามตัวอักษร

## 3. หมวดหมู่คำศัพท์ในชีวิตประจำวัน (topic)

ทุกคำต้องมี `topics` อย่างน้อย 1 หมวด เพื่อให้จับคู่กับหัวข้อบทเรียนได้

| topic | ตัวอย่าง |
|---|---|
| `greetings` ทักทาย | hello, thanks, sorry, please |
| `people_family` คนและครอบครัว | mother, friend, child, husband |
| `body_health` ร่างกายและสุขภาพ | head, ill, doctor, medicine |
| `food_drink` อาหารและเครื่องดื่ม | rice, coffee, hungry, cook |
| `home` บ้าน | room, kitchen, bed, clean |
| `daily_routine` กิจวัตร | wake up, wash, breakfast, usually |
| `time_dates` เวลาและวันที่ | Monday, hour, early, tomorrow |
| `numbers_money` ตัวเลขและเงิน | hundred, price, cheap, pay |
| `shopping` ซื้อของ | shop, buy, size, receipt |
| `clothes` เสื้อผ้า | shirt, shoes, wear |
| `places_city` สถานที่และเมือง | bank, street, near, left |
| `travel_transport` เดินทาง | bus, ticket, airport, hotel |
| `work_study` งานและการเรียน | job, office, meeting, exam |
| `weather_nature` อากาศและธรรมชาติ | rain, hot, tree, sea |
| `hobbies_sport` งานอดิเรกและกีฬา | music, film, football, swim |
| `technology` เทคโนโลยี | phone, email, internet, download |
| `feelings` ความรู้สึก | happy, tired, worried, angry |
| `communication` การสื่อสาร | ask, explain, agree, opinion |
| `function_words` คำเชื่อมและคำไวยากรณ์ | the, because, although, which |

## 4. คลังคำศัพท์ใน repo

คำศัพท์ทั้งหมดอยู่ที่เดียวคือ `content/vocab/` บทเรียนอ้างถึงคำด้วย ID เท่านั้น จึงไม่มีการเก็บข้อมูลคำซ้ำ

```
content/vocab/
├── oxford-3000/
│   ├── a1.json
│   ├── a2.json
│   ├── b1.json
│   └── b2.json
└── oxford-5000/
    └── b2-c1.json
```

รูปแบบข้อมูลของแต่ละคำดูได้ที่ [CONTENT_SCHEMA.md](CONTENT_SCHEMA.md#vocabitem)

## 5. ฟีเจอร์คำศัพท์ในแอป

- **Word Bank** (`/words`): ดูคำศัพท์ทั้งหมด กรองตามระดับ หมวด และสถานะ (ยังไม่เรียน / กำลังเรียน / จำได้แล้ว)
- **หน้ารายละเอียดคำ:** IPA และเสียงทั้งแบบ US/UK, คำแปลไทย, ตัวอย่างประโยค, collocation, รูปผันของคำ, ปุ่มอัดเสียงฝึกออกเสียง
- **SRS ด้วย FSRS:** ฝึกจากหลายทิศทาง
  - อังกฤษ → ไทย (จำความหมาย)
  - ไทย → อังกฤษ (นึกคำออก)
  - ฟังเสียง → สะกดคำ (ฟังและสะกด)
  - พูดคำ → ให้คะแนนการออกเสียง
- **Oxford progress:** แสดงความคืบหน้า เช่น "รู้แล้ว 1,234 / 3,000 คำของ Oxford 3000" แยกตามระดับ A1–B2
- **Tap-to-lookup:** ในบทอ่าน แตะคำไหนก็ได้เพื่อดูความหมาย และกดเพิ่มเข้า SRS ได้

## 6. กฎการตรวจ (`pnpm content:validate`)

1. ทุก vocab ID ที่บทเรียนอ้างถึงต้องมีอยู่ในคลัง
2. แต่ละคำต้องถูกสอนเป็นคำใหม่ (`vocab`) **เพียงครั้งเดียว** ทั้งหลักสูตร
3. ระดับ Oxford ของคำต้องไม่สูงกว่าระดับ `cefr` ของบทเรียนนั้น (ลำดับ `preA1` < `A1` < `A2` < `B1` < `B2` < `C1`) ตรวจเฉพาะคำใน `vocab` ของบท (คำที่สอนเป็นคำใหม่) **ข้อยกเว้น:** บท `preA1` สอนคำ A1 ได้ (เฟส 1 สอนคำ A1 ที่ใช้บ่อยที่สุดให้ผู้เรียนระดับ pre-A1) แต่ยังสอนคำ A2 ขึ้นไปไม่ได้
4. `topics` ของทุกคำต้องเป็น slug ที่อยู่ในหัวข้อ 3 และห้ามซ้ำในคำเดียวกัน
5. ID ของคำในคลังต้องไม่ซ้ำกันทั้งคลัง และไม่มีสองรายการที่มี (`word` ตัวพิมพ์เล็ก, `pos`) เหมือนกัน
6. `id` ต้องเป็น `v-<slug(word)>` หรือ `v-<slug(word)>-<slug(pos)>` โดย slug = ตัวพิมพ์เล็ก แทนทุกช่วงอักขระที่ไม่ใช่ `a-z0-9` ด้วย `-` ตัวเดียว และตัด `-` หน้า/หลัง (`wake up` → `wake-up`, `o'clock` → `o-clock`, `auxiliary verb` → `auxiliary-verb`)
7. Oxford: list `3000` ใช้ระดับ A1–B2, list `5000` ใช้ระดับ B2–C1 และต้องตรงกับไฟล์: `oxford-3000/<level>.json` ต้องเป็น list `3000` ระดับนั้น, `oxford-5000/*.json` ต้องเป็น list `5000`
8. exercise ที่อ้างคำ (`vocab_match`, `spell_word`, `use_in_sentence`) ต้องอ้างเฉพาะคำที่ถูกสอนเป็นคำใหม่ในบทเดียวกันหรือวันก่อนหน้า
9. คำใหม่ (`vocab` ไม่ว่าง) ใส่ได้เฉพาะบท `type: "lesson"` และไม่เกิน 12 คำต่อบท; คำเดียวห้ามอยู่ใน `vocab` ของบทเดียวกันสองครั้ง
10. รายงานความครอบคลุม: จำนวนบทเรียน, จำนวนคำในคลัง, จำนวนคำที่ถูกสอนเป็นคำใหม่แล้ว และจำนวนคำที่ยังไม่ถูกใส่ในบทเรียนใดเลย

กฎของบทเรียนที่ตรวจพร้อมกัน (ดู [CONTENT_SCHEMA.md](CONTENT_SCHEMA.md#กฎที่-contentvalidate-ตรวจเพิ่ม)): ชื่อไฟล์ตรงกับ `day`, exercise ID ไม่ซ้ำและมีเลขวันตรงกับบท, เฉลยสอดคล้องกับตัวเลือก

## 7. ลิขสิทธิ์

รายการ Oxford 3000/5000 เป็นลิขสิทธิ์ของ Oxford University Press
- เก็บจาก Oxford เฉพาะ **ข้อมูลพื้นฐานของคำ** คือ headword, ชนิดของคำ และระดับ CEFR
- **คำแปลไทย, ตัวอย่างประโยค และ collocation ต้องเขียนเอง** ห้ามคัดลอกคำนิยามหรือตัวอย่างจากพจนานุกรม Oxford
- ก่อนเปิดให้คนทั่วไปใช้ ต้องตรวจเงื่อนไขการใช้งานรายการนี้ของ OUP อีกครั้ง
