# Design

ข้อเสนอการออกแบบ UI เก็บเป็นไฟล์ FigCraft (`.figcraft`) พร้อมรูป PNG ของแต่ละหน้าจอ

## ui-dark-v1: โหมดมืด เรียบ สะอาด ดูจริงจัง (ข้อเสนอ ยังไม่ได้ทำในโค้ด)

| ไฟล์ | คืออะไร |
|---|---|
| `ui-dark-v1/ui-dark-v1.figcraft` | ไฟล์ออกแบบ เปิดด้วย FigCraft เพื่อดูหรือแก้ |
| `ui-dark-v1/overview.png` | ทุกหน้าจอในรูปเดียว |
| `ui-dark-v1/screens/*.png` | แต่ละหน้าจอ (360×760 ที่ 2x) |
| `ui-dark-v1/build.py` | สคริปต์ที่สร้างไฟล์ออกแบบ |

หน้าจอ: หน้าแรก, แนะนำเสียง, ฟังแยกเสียงหลังตรวจคำตอบ, แปลประโยคขณะพิมพ์, จบบทเรียน (โหมดมืด) และหน้าแรกกับฟังแยกเสียงในโหมดสว่างไว้เทียบ และหน้าตั้งค่าธีมทั้งสองโหมด

### ธีม (ผู้ใช้ตัดสินใจ 2026-11-25)
เลือกได้ 3 แบบในหน้าตั้งค่า: **สว่าง**, **มืด**, **ตามเครื่อง** (ค่าเริ่มต้น ตาม `prefers-color-scheme` ของอุปกรณ์)
- จำค่าไว้ต่ออุปกรณ์ (cookie) ไม่เก็บในฐานข้อมูล มือถือกับคอมจึงตั้งต่างกันได้ และหน้าแรกไม่กะพริบผิดสีตอนโหลด
- สีทั้งหมดในโค้ดต้องอ้างผ่านตัวแปรสี (design token) ชุดเดียว ห้ามใส่รหัสสีตรงๆ ใน component
- เข้าหน้าตั้งค่าจากปุ่มเฟืองที่มุมขวาบนของหน้าแรก

### แนวทาง
- สีเน้นสีเดียว (น้ำเงินอมม่วง) ใช้กับปุ่มหลักและแถบความคืบหน้าเท่านั้น
- เขียว / แดง ใช้เฉพาะผลถูกผิด และมีเครื่องหมาย ✓ ✗ กำกับเสมอ
- แถบเฉลยและปุ่ม "ถัดไป" ติดอยู่ล่างจอ ไม่ต้องเลื่อนหา
- ฟอนต์: Noto Sans Thai (ไทย), Inter (อังกฤษ), Noto Sans (IPA)

### สร้างไฟล์ใหม่จากสคริปต์
```bash
cd design/ui-dark-v1
python3 build.py /tmp/ui.json
figcraft-cli run /tmp/ui.json --out ui-dark-v1.figcraft
figcraft-cli export ui-dark-v1.figcraft --out screens --scale 2
```
สคริปต์อ้าง id ของ layer ตามลำดับที่สร้าง (เริ่มที่ 2) จึงต้องรันกับเอกสารใหม่เท่านั้น

หน้าจอในข้อเสนอนี้มีข้อมูลที่แอปยังไม่มี (จำนวนคำที่เรียนแล้ว, คะแนนบทล่าสุด, "ควรฝึกเพิ่ม", ระดับโดยประมาณ) ซึ่งมาจากสูตรใน `docs/PROGRESS.md` ที่ยังไม่ได้ต่อกับหน้าจอ

### เมนูหลัก (ผู้ใช้เลือก 2026-11-25)
เสนอ 3 แบบ (A แถบลอยทรงแคปซูล, B หน้าแรกเป็นศูนย์กลาง, C ปุ่มเรียนต่ออยู่กลางแถบ; ดู `ui-dark-v1/nav-compare.png`) ผู้ใช้ชอบ "ลอยแบบ A" และ "เน้นเมนูปัจจุบันให้ใหญ่แบบ C" จึงรวมเป็น **แบบ D** (`ui-dark-v1/nav-d-combined.png`, `screens/13-nav-d-*.png`):
- แถบลอยทรงแคปซูลเหนือขอบล่าง มี 4 เมนู: วันนี้, ฝึกเพิ่ม, พัฒนาการ, ตั้งค่า ทุกเมนูมีไอคอนและชื่อ
- เมนูที่อยู่ตอนนี้เป็นวงกลมสีเน้นขนาดใหญ่ยกขึ้นเหนือแถบ พร้อมชื่อสีเน้นตัวหนา
- ไม่แสดงแถบเมนูในหน้าเล่นบทเรียน

### การตัดสินใจของผู้ใช้
| เรื่อง | ที่เลือก |
|---|---|
| โทนสี | ตามตารางสีด้านบน (มืดและสว่าง) |
| ธีม | เลือกได้ สว่าง / มืด / ตามเครื่อง ในหน้าตั้งค่า |
| เมนูหลัก | แถบลอยเหนือขอบล่าง 4 เมนู (วันนี้, ฝึกเพิ่ม, พัฒนาการ, ตั้งค่า) เมนูที่อยู่ตอนนี้เป็นวงกลมสีเน้นขนาดใหญ่ยกขึ้นเหนือแถบ **ไม่มีชื่อกำกับ** และ**ขอบบนของแถบยุบโค้งตามวงกลม** เมนูอื่นแสดงไอคอนกับชื่อ |
| ฝึกเพิ่ม | ฝึกนอกบทประจำวันได้ โดยเลือกทักษะและหัวข้อเองจาก**เนื้อหาที่เรียนในบทประจำวันไปแล้ว**เท่านั้น (ไม่เปิดเนื้อหาล่วงหน้า) รวมทวนคำศัพท์ ฝึกจุดอ่อน และเล่นบทเดิมซ้ำ |
| สตรีค | การฝึกเพิ่ม**นับเป็นสตรีค**ด้วย โดยนับเมื่อ**จบชุดฝึก 1 ชุด (10 ข้อ)** หรือทวนคำศัพท์ที่ถึงกำหนดครบ (เพิ่มจากเดิมที่นับเมื่อจบบทประจำวัน) ตอบข้อเดียวไม่นับ |
| พัฒนาการ | มีหน้าแสดงระดับโดยประมาณ, ตามแผน 365 วัน, คำศัพท์ Oxford 3000, จุดอ่อนพร้อมปุ่มฝึก/ทดสอบ |

### สิ่งที่การตัดสินใจนี้กระทบในโค้ดและเอกสาร (ยังไม่ได้ทำ)
- `docs/PROGRESS.md` §5: เพิ่มเงื่อนไขนับสตรีคเมื่อจบชุดฝึกเพิ่ม 1 ชุด (10 ข้อ); บทฝึกและบททดสอบจุดอ่อน และการเล่นบทเดิมซ้ำจนจบ ถือเป็นชุดฝึกเช่นกัน
- ทวนคำศัพท์ใช้ปุ่มให้คะแนน 4 ระดับ (จำไม่ได้ / ยาก / ได้ / ง่าย) ตรงกับ rating 1–4 ของ FSRS และแสดงระยะเวลาที่จะกลับมาทวนใต้ปุ่ม
- การเล่นบทเดิมซ้ำไม่เปลี่ยนคะแนนเดิมของบท
- ฐานข้อมูล: `attempts.source` ต้องมีค่าใหม่สำหรับการฝึกเพิ่ม (เช่น `practice`) และ `activity_days.source` เช่นกัน
- สูตรจุดอ่อน: คำตอบจากการฝึกเพิ่มไม่นับเป็นการตรวจพบจุดอ่อน (เหมือน `drill`)
- แถบเมนูไม่แสดงในหน้าเล่นบทเรียน
- สีทั้งหมดต้องอ้างผ่าน design token ชุดเดียว เพื่อรองรับสามธีม
